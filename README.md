# Quantitative Risk Modeling (FAIR Framework) Case Study

## Project Overview

This repository showcases the application of the **FAIR (Factor Analysis of Information Risk)** framework to quantify cybersecurity risk in financial terms. Instead of using qualitative "High/Medium/Low" terms, this project uses mathematical modeling to **provide leadership with actionable data** they can use to determine whether they should purchase a cybersecurity control from a business standpoint.

## Scenario

After experience two DDoS attacks last week, a medium-sized organization is evaluating whether to invest in the **Microsoft Azure DDoS Protection plan**. The issue is that Microsoft Azure DDoS protection plan **costs ~$36,000** per year. Furthermore, the organization knows that having this protection does not guarantee DDoS attacks will no longer occur.

## Methodology

To solve the problem posed in the scenario, the **FAIR framework** is used to determine whether the financial loss prevented by the Microsoft Azure DDoS Protection plan outweighs its cost. A walkthrough of this framework, along with this scenario, can be found in my blog post [Understanding Cyber Risk Quantification for Business](https://feelthefevercyber.com/2026/03/09/understanding-cyber-risk-quantification-for-business/).
